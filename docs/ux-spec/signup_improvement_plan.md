# NextPartner Fair 회원가입 UX 개선 기획안

> **목적:** 시니어 구직자의 디지털 접근성과 사용성을 높여 회원가입 완료율을 개선한다.
> **범위:** 기존 5단계 회원가입 플로우 전체 (항목 추가·삭제 없음, 디자인 시스템 변경 없음)

---

## 1. 현황 분석 및 개선 방향

### 1-1. 시니어 사용자의 주요 불편 요소

| 구분 | 현재 문제점 | 개선 방향 |
|------|------------|----------|
| 정보 부담 | 한 화면에 많은 입력 필드 노출 | 필드 그룹핑, 단계별 안내 강화 |
| 오류 처리 | 오류 발생 시 원인 파악 어려움 | 실시간 인라인 검증 + 구체적 안내 문구 |
| 진행 상황 | 전체 흐름 파악이 어려움 | 진행률 표시 문구 보강 |
| 이력서 연동 | 입력 데이터와 이력서 연결 인지 불가 | 단계별 이력서 반영 안내 장치 추가 |
| 선택지 이해 | 버튼/옵션 의미 불명확 | 툴팁, 보조 설명 추가 |

---

## 2. 공통 개선 사항 (전 단계 적용)

### 2-1. 진행 상황 표시 강화

**현재:** 단계 번호(1~5)와 단계명만 표시
**개선:**
- 스텝 바 하단에 `"5단계 중 1단계 완료"` 형식의 텍스트 보조 표시
- 좌측 사이드 패널의 퍼센트(20%, 40% …)를 `"거의 다 왔어요! 1단계 남았습니다"` 형태의 격려 문구로 보완
- 각 단계 완료 시 `"✓ 저장되었습니다"` 피드백 노출 (다음 단계로 이동 직전)

### 2-2. 이력서 자동 반영 안내 장치

회원가입 입력 정보가 이력서에 자동 반영된다는 사실을 사용자가 인지할 수 있도록 세 곳에 안내를 배치한다.

| 위치 | 안내 문구 예시 | 표시 시점 |
|------|--------------|----------|
| 회원가입 시작 화면 상단 (Step 1 진입 전) | "입력하신 정보는 AI 이력서에 바로 반영됩니다. 정확하게 입력할수록 더 좋은 공고를 추천받을 수 있어요." | 최초 1회 |
| 각 단계 우측 폼 상단 (인라인 배너) | "📄 이 정보는 이력서의 [기본 정보 / 학력 / 경력 / 자격증 / 희망 조건] 항목에 자동 저장됩니다." | 단계별 항상 표시 |
| 최종 완료 화면 | "회원가입이 완료되었습니다. 입력하신 정보로 이력서 초안이 만들어졌어요. 지금 바로 확인해보세요." | 완료 시 |

> **UX 원칙:** 안내 배너는 접을 수 있도록 하되, 접은 상태는 세션 내에서만 유지 (재방문 시 다시 표시)

### 2-3. 버튼 및 액션 레이블 개선

| 현재 | 개선 | 이유 |
|------|------|------|
| 다음 | 저장하고 다음 단계로 | 저장 여부 불명확 |
| 이전 | 이전 단계로 (입력 내용 유지) | 이전 이동 시 데이터 소실 우려 해소 |
| 이벤트에서 등록 완료 | 이력서 만들고 가입 완료하기 | 완료 후 이어질 행동 예고 |

### 2-4. 필수 항목 표시 방식 개선

- `*` 표시와 함께 폼 상단에 `"* 표시 항목은 필수입니다"` 범례를 추가
- 선택 항목에는 `(선택)` 텍스트를 병기하여 부담 경감

### 2-5. 오류 메시지 구체화

| 현재 | 개선 |
|------|------|
| 이메일 형식이 올바르지 않습니다 | 이메일 주소를 확인해주세요. 예) example@naver.com |
| 비밀번호가 일치하지 않습니다 | 위에 입력한 비밀번호와 동일하게 다시 입력해주세요 |
| (오류 없음, 통과만 표시) | ✓ 사용 가능한 이메일입니다 (실시간 인라인 확인) |

## 3. 단계별 개선 상세

---

### STEP 1 — 기본 정보 입력

**현재 구조:** 이름, 성별, 이메일, 생년월일(6자리), 전화번호, 비밀번호, 비밀번호 확인을 한 화면에 노출

#### 개선 포인트

**① 입력 필드 그룹 분리 및 시각적 구분**
- `개인 식별 정보` 그룹: 이름, 성별, 생년월일, 전화번호
- `계정 정보` 그룹: 이메일, 비밀번호, 비밀번호 확인
- 그룹 사이에 구분선 또는 소제목 레이블 삽입

**② 생년월일 입력 보조**
- 현재: 텍스트 입력(YYMMDD 6자리)
- 개선: 입력 필드 내 마스크 패턴 `YY/MM/DD` 자동 슬래시 삽입 + 플레이스홀더를 `예) 850312`에서 `생년월일 6자리 (예: 850312)`로 변경
- 입력 완료 후 자동 파싱하여 `"1985년 3월 12일로 확인되었습니다"` 문구 노출

**③ 전화번호 자동 하이픈**
- 숫자 입력 시 자동으로 `010-XXXX-XXXX` 포맷 적용
- 플레이스홀더: `숫자만 입력하세요 (예: 01012345678)`

**④ 비밀번호 조건 인라인 표시**
- 입력 시작 즉시 조건 체크리스트를 인라인으로 표시
  - ☐ 8자 이상
  - ☐ 영문 포함
  - ☐ 숫자 포함
  - ☐ 특수문자 포함
  - ☐ 비밀번호 확인 일치
- 조건 충족 시 ☑ 체크 표시로 실시간 업데이트

**⑤ 이력서 연동 안내 배너**
- 폼 상단에 삽입
- 문구: `"📄 이 정보는 이력서 기본 정보란에 자동 반영됩니다"`

---

### STEP 2 — 학력 상세

**현재 구조:** 최종학력 선택(중졸이하/고졸/대학교/대학원), 학교명, 전공, 입학년도, 졸업구분

#### 개선 포인트

**① 최종학력 선택에 따른 조건부 표시 안내 명확화**
- 현재: 상단에 작은 안내 문구 1줄
- 개선: 선택지 아래에 `"대학교 선택 시 → 학교명·전공·입학년도·졸업구분을 입력합니다"` 형태의 미리보기 안내

**② 졸업구분 드롭다운 옵션 레이블 명확화**
- 현재: `선택하세요` (옵션 내용 미확인)
- 개선: 옵션 구성을 `졸업 / 재학 중 / 중퇴 / 수료` 명시 + 각 옵션에 간단 설명 추가 (재학 중: 현재 다니고 있음)

**③ 학교명 입력 보조**
- 자동완성(학교명 검색) 기능이 없을 경우, 플레이스홀더를 `예) OO대학교` → `예) 서울대학교, 한국대학교` 처럼 실제 예시로 변경

**④ 이력서 연동 안내 배너**
- 문구: `"📄 이 정보는 이력서 학력 항목에 자동 반영됩니다"`

---

### STEP 3 — 경력 사항

**현재 구조:** 경력 추가 버튼, 경력 카드(회사명, 담당 직무, 시작일, 종료일, 현재 재직 중 체크박스)

#### 개선 포인트

**① 경력 없음 처리 명확화**
- 현재: 상단에 작은 텍스트로 `"경력이 없으시면 다음으로 넘어가도 됩니다"` 표시
- 개선: 별도의 `"경력 없음(신입)"` 버튼 또는 체크박스를 상단에 배치
  - 선택 시 경력 입력 폼이 비활성화되고 `"신입으로 등록됩니다"` 확인 메시지 표시

**② 날짜 입력 방식 개선**
- 현재: 브라우저 기본 date picker
- 개선: 년도·월 분리 셀렉트박스 (`2020년 ▾ / 3월 ▾`) 로 변경하여 조작 편의성 향상

**③ 현재 재직 중 체크박스 연동**
- 현재 재직 중 체크 시 종료일 필드 자동 비활성화 + `"현재 재직 중"` 텍스트 표시

**④ 경력 카드 삭제 확인**
- `× 삭제` 클릭 시 즉시 삭제 대신 `"이 경력을 삭제할까요? [삭제] [취소]"` 확인 레이어 표시

**⑤ 이력서 연동 안내 배너**
- 문구: `"📄 이 정보는 이력서 경력 항목에 자동 반영됩니다"`

---

### STEP 4 — 자격증

**현재 구조:** 자격증 추가 버튼, 자격증 카드(자격증명, 발급기관, 취득일)

#### 개선 포인트

**① 자격증 없음 처리 명확화**
- STEP 3과 동일하게 `"자격증 없음"` 체크박스 상단 배치

**② 자격증명 입력 보조**
- 플레이스홀더에 카테고리 힌트 추가: `예) 운전면허, 정보처리기사, 요양보호사`
- 자격증 종류 선택 드롭다운(1차 분류)을 제공하고 직접 입력도 허용

**③ 발급기관 플레이스홀더 개선**
- 현재: 빈 텍스트 필드
- 개선: `예) 한국산업인력공단, 도로교통공단`

**④ 취득일 입력 방식 개선**
- STEP 3 날짜 입력과 동일하게 년도·월 셀렉트박스 적용

**⑤ 이력서 연동 안내 배너**
- 문구: `"📄 이 정보는 이력서 자격증 항목에 자동 반영됩니다"`

---

### STEP 5 — 희망 조건 설정

**현재 구조:** 희망 직무(태그 다중 선택), 희망 근무 형태(드롭다운), 희망 근무 지역(드롭다운), 희망 연봉(입력)

#### 개선 포인트

**① 희망 직무 태그 선택 보조**
- 현재: 태그를 한눈에 보는 그리드 형식 (3개까지 선택)
- 개선:
  - 선택된 태그 영역을 별도로 상단 분리하여 `"선택한 직무: IT개발, 디자인"` 형태로 표시
  - 태그 위에 마우스 오버(또는 탭 탐색) 시 직무 설명 툴팁 제공 (`IT·개발: 개발자, 시스템 운영 등`)
  - `"최대 3개까지 선택 가능"` 문구를 태그 그리드 바로 위에 배치 (현재보다 더 눈에 띄게)

**② 희망 근무 형태 옵션 레이블 명확화**
- 드롭다운 옵션에 설명 추가
  - 정규직: 기간 정함 없이 근무
  - 계약직: 기간을 정해 근무
  - 아르바이트: 시간제·단기 근무
  - 파견직, 프리랜서 등

**③ 희망 근무 지역 다중 선택 안내**
- 현재: 단일 드롭다운
- 개선: `"최대 3개 지역까지 선택할 수 있습니다"` 안내 문구 추가 (다중 선택 가능하다면)

**④ 희망 연봉 입력 보조**
- 숫자 입력 시 자동으로 `"2,400만 원"` 형식으로 포맷팅
- 하단에 `"연봉은 매칭 공고 필터에 사용되며 기업에는 공개되지 않습니다"` 안내 문구 추가

**⑤ 완료 전 입력 요약 표시**
- `"이벤트에서 등록 완료"` 버튼 위에 사용자가 선택한 값 요약 표시
  ```
  ✓ 희망 직무: IT·개발, 디자인
  ✓ 근무 형태: 정규직
  ✓ 근무 지역: 서울
  ✓ 희망 연봉: 3,600만 원
  ```
- 수정이 필요할 경우 각 항목 옆 `[수정]` 링크로 해당 필드로 포커스 이동

**⑥ 이력서 연동 안내 배너**
- 문구: `"📄 이 정보는 이력서 희망 조건 항목에 자동 반영됩니다. 완료 후 이력서에서 바로 확인하실 수 있어요."`

---

## 4. 좌측 사이드 패널 개선 (전 단계 공통)

좌측 패널은 현재 단계 아이콘, 단계명, 설명 텍스트, 진행률만 표시. 아래 내용을 보강한다.

| 현재 | 개선 |
|------|------|
| 단계명(한글) + 설명 2줄 | 단계명 + 설명 + **"이 정보는 이력서에 저장됩니다"** 보조 문구 추가 |
| 20% / 40% ... 숫자만 | `20% 완료 — 4단계 남았습니다` 형태의 텍스트 보강 |
| 고정 안내 문구 1개 | 단계별로 다른 맥락 메시지 노출 (예: STEP 3 경력 → "경력이 없어도 괜찮아요. 신입도 환영합니다!") |

---

## 5. 접근성 체크리스트

시니어 친화 사용성을 위해 아래 항목을 구현 시 반드시 확인한다.

- [ ] 모든 입력 필드에 `label` 연결 (스크린 리더 지원)
- [ ] 포커스 순서가 논리적 흐름(위→아래, 좌→우)을 따름
- [ ] 오류 메시지는 색상만이 아닌 텍스트로 명시
- [ ] 버튼 클릭 영역 최소 44×44px 이상
- [ ] 키보드만으로 전체 폼 완성 가능
- [ ] 자동완성(autocomplete) 속성 설정 (이름, 이메일, 전화번호 등)
- [ ] 탭 이동 시 현재 포커스 위치 시각적으로 확인 가능

## 6. 개선 우선순위

| 우선순위 | 항목 | 예상 효과 |
|---------|------|----------|
| P0 (즉시) | 이력서 자동 반영 안내 배너 (전 단계) | 서비스 가치 전달, 완료율 상승 |
| P0 (즉시) | 오류 메시지 구체화 | 입력 오류로 인한 이탈 감소 |
| P1 (단기) | 비밀번호 조건 실시간 체크리스트 | 비밀번호 오류 재시도 감소 |
| P1 (단기) | 경력·자격증 "없음" 명시 버튼 | 단계 이탈 감소 |
| P1 (단기) | 전화번호·날짜 자동 포맷팅 | 입력 편의성 향상 |
